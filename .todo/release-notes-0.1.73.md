## Hermes UI v0.1.73

从 v0.1.72 到 v0.1.73 的累计更新（App 内「检查更新」会直接跳到本版）。

本轮主线是**全应用分割线的一次收口** —— 从「各页各写一套线」到「一条常驻发丝线 + 语义分级令牌」，
外加多图附件宫格的排布重做。

### 分割线：全应用收敛为「一条常驻发丝线」

**问题**（主人报告）：有内容的会话与刚新建的会话，顶栏下沿那条线深浅不一样，向下一滚动就变深。

**根因**：Flutter 的 `CupertinoNavigationBar` 默认带一条 `#4D000000`（黑 30%）边框，在
`CupertinoPageScaffold` 内由滚动位置驱动、10 逻辑像素内从透明淡入；而页面自己又画了一条 0.5px
发丝线 ⇒ 只要内容能滚动，两条线就叠一起（像素取证：带内容 `#B9B9B9` vs 新建 `#E3E3E3`，底色同为 `#F2F2F2`）。

**改法**：

- 聊天页显式关掉 SDK 那条边框（`border: null`），改用**常驻发丝线** `NavBarHairline`
  （0.5 逻辑像素、取结构线令牌色）—— 线不再随滚动淡入，深浅恒定。
- 盘点全仓 **43 处导航栏**：此前并存三套线色（SDK 默认黑 30% / 写死 `#4D000000` / 部分页已用令牌）
  与 0.0 / 0.5 / 1.0 三档宽度 ⇒ 统一走线族令牌，**24 处导航栏零异色、宽度统一 0.5**。
- 新增**分割线语义分级令牌**（L1 / L2 / L3，`lib/app/theme/divider_tokens.dart`）：
  分割线从此只有一个出口，不再有零散写死的线色。
- 新增共享件 `NavBarHairline` / `NavBarBottom`，**25 处导航栏接线**（设置系 13 + 看板 2 + 诊断 2
  + 下载 / 后台保活 / 任务 / 引导 ×2 / 安装指引 / Mermaid 全屏）。宽屏固定条总高 44.5
  （与侧栏品牌栏 44 落在同一视觉轴）；窄屏大标题头部下沿同样常驻一条线。
- **刻意不动**（各有独立对比度口径，非漏改）：看板深色卡片装饰线、输入栏 chip 深色描边、
  Mermaid 图表调色板、全屏媒体查看器的恒黑栏。
- 新增**源码级守卫**：扫 `lib/` 断言每个 `CupertinoNavigationBar` 都「关掉 SDK 边框 + 常驻发丝线」，
  例外必须在测试里白名单写明理由 —— 以后新增页面漏接线，会被测试当场抓住。

### 多图附件：宫格改「单行等高」

- **非方图不再被裁成方块**：多图附件改为单行等高排布（justified gallery）—— 行内等高、每张按自身
  宽高比分配宽度，不裁切、不留白，整行填满气泡可用宽；张数多或比例极端时按具名常量分行与收高，
  任何输入都不溢出。
- **末行孤张规避**：贪心封行后若下一行只剩一张（4 张会排成 3+1），那张会被收成一个大方块、
  整行还填不满（旧形态块高 279pt）⇒ 封行时主动退一张，4 张变 2+2（两行都填满，块高 196pt）。
- **修一处潜在崩溃**：同一条消息里两张同名附件会撞同一个 `ValueKey`（debug 直接抛
  `Duplicate keys found`）⇒ 重复项按出现顺序加 `#n` 后缀，首张锚点不变。
- 未解码时按 1:1 稳定占位（首帧不塌陷）；单图的 `contain` 路径与文件行条未动。

### 其他修复

- **设置页分段控件选中标签对比度**：深色下选中段与未选中段共用同一个「次级色」，合成到更亮的
  胶囊上只剩 **2.94:1**（低于 AA 4.5:1）—— 选中项成了整行对比度最弱的元素。选中段改主标签色后
  **2.94 → 5.99:1**（浅色 5.38 → 21.00:1），胶囊本体保持 iOS 原生取值。
- **自动加载图片闸门两处**：① 关闭自动加载时，加载按钮/提醒不在占位正中（贴左上角、96 瓦片里
  文字折成两行）；② 返回再点开同一消息后图片又退回「点击加载」（放行态随瓦片卸载即丢）
  ⇒ 占位改居中（内容中心偏移 ≤1px）+ 放行态记进进程级集合（只记 URL、不落盘、重启即清）。
- **移除消息行悬停浮出的「⋯」**：它浮在行尾会遮挡正文。右键、`Shift+F10` / 菜单键（带焦点环）、
  窄屏长按**逐字未动**。
- **宽屏下「新建会话自动打开上下文」视为未开启**：宽屏上下文弹层已只剩读数、没有可设置项
  （2026-10-07 已移除「当前模型 / 工作区」两个入口），自动弹出来没意义；窄屏语义不变。

### 质量

- `flutter analyze` 零告警；全量 `flutter test` **5641 通过 / 230 skipped / 0 失败**（Windows 本机实测）。
- 金照基线 **Windows / Linux 双平台同步补齐**（各 22 张），像素取证：18 张窄屏图**整体下移
  1 物理像素后与原基准逐点 100% 一致**（不移位仅 ~91%）⇒ 纯位移、零结构性变化，
  变化行就是那条线本身。
- 每处修复都配**源码级守卫**（悬停不得新增「⋯」、同名附件不得抛异常、justified 排布不得出现
  被收高的孤张行、宽屏不得自动弹上下文、分段标签对胶囊 ≥4.5:1、导航栏必须常驻发丝线），
  并逐条做了 RED 校验（回退改动 ⇒ 守卫精确变红）。
